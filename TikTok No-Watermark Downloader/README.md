# TikTok No-Watermark Downloader

在 TikTok 网页版下载无水印的视频、图集和视频集。Chrome / Edge Manifest V3 浏览器扩展。

姊妹扩展：[Douyin-No-Watermark-Download](../Douyin-No-Watermark-Download)

## 功能

- **无水印下载**：支持单视频、图集（多图）、视频集和混合作品
- **两种下载模式**
  - **高清**（默认）：优先下载高清流（如 1080p H.265），视频不含音轨时自动补下一个 `.m4a` 音频文件
  - **兼容**：下载 TikTok 的合成流，单文件含音频，画质较低
- **画质选择**：最高 / 次高 / 最低，最高画质失效时自动降级
- **弹窗下载入口**：点击扩展图标可预览当前作品（类型 / 标题 / 作者），一键下载
- **快捷键**：页内 `Shift + D`；全局 `Alt + D`（可在 `chrome://extensions/shortcuts` 自定义）
- **文件名模板**：支持 `{title}`、`{author}`、`{id}`、`{date}` 占位符
- **保存位置**：使用系统保存框，自动记住上次位置

## 安装

1. 下载本仓库（Code → Download ZIP，或 `git clone`）
2. 打开 `chrome://extensions/`，右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本文件夹

更新：用新版本覆盖旧目录后，在扩展页点击刷新图标即可。

## 使用

打开任意 TikTok 视频 / 图集页面，按 `Shift + D`（或全局 `Alt + D`）即可下载；也可以点击扩展图标，在弹窗中预览作品后点击「下载当前作品」。画质、文件名模板等设置都在弹窗里。

高清模式若得到分离的 mp4 + m4a 两个文件，可用 ffmpeg 无损合并：

```bash
ffmpeg -i video.mp4 -i audio.m4a -c copy output.mp4
```

## 注意事项

- 信息流（推荐页）滚动时当前作品可能识别不准，建议先点开作品再下载
- 高清模式补下音频时，浏览器会询问是否允许下载多个文件，需要点「允许」
- 音频取自作品数据中的 `music.playUrl`：原声作品音画同步；使用他人 BGM 的作品，音频就是该 BGM（TikTok 数据本身的限制）
- 高清模式的 mp4 可能比兼容模式更小，这是 H.265 压缩率更高的原因，不代表画质低
- 如果某天突然识别不到作品，通常是 TikTok 接口结构更新，等待扩展更新即可

## 隐私

- 不收集任何数据
- 设置仅保存在你自己的浏览器中
- 仅在下载时直连 TikTok 的 CDN，Cookie 不会发送到其他站点

## 开发

代码无构建步骤，纯原生 JS：修改后在扩展页刷新即可。开启弹窗里的「调试日志」，可在浏览器 Console 查看解析过程。
