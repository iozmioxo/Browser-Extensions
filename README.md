# Tool-box

浏览器扩展工具索引。每个工具均已拆分为独立仓库，请前往对应仓库查看代码、安装说明和版本历史。

## 工具列表

- [TikTok No-Watermark Downloader](https://github.com/iozmioxo/TikTok-No-Watermark-Downloader)：Chrome / Edge Manifest V3 扩展，用于在 TikTok 网页版下载无水印视频、图集和视频集。
- [Douyin-No-Watermark-Download](https://github.com/iozmioxo/Douyin-No-Watermark-Download)：Chrome / Edge Manifest V3 扩展，用于在抖音网页版下载无水印视频、图文和视频集。
- [TikTok Comment Translation](https://github.com/iozmioxo/TikTok-Comment-Translation)：Chrome / Edge Manifest V3 扩展，为 TikTok 网页端评论添加多服务商翻译按钮。
- [Subtitle Translate](https://github.com/iozmioxo/Subtitle-Translate)：Chrome / Edge Manifest V3 扩展，用于在 Netflix 网页端预翻译字幕并显示双语字幕。
